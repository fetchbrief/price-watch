**每天早上，自动盯住你关心的数字，出一份中文日报 —— 不用你手动刷。**

> 做外贸的盯汇率、做电商的盯价格、做研究的盯公开数据。
> 你把「要盯什么」告诉它，它替你抓、替你写。
> （下面演示用的真实数据源是公开汇率接口，换成商品价格、榜单、库存表都一样。）

## 如何运行

需要 Python 3.9+（开发环境为 3.14）。

```bash
# 1. 进入项目目录并创建虚拟环境
cd price-watch
python -m venv .venv
.venv\Scripts\activate        # Windows；macOS/Linux 用 source .venv/bin/activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置密钥（只放进 .env，绝不提交）
#    在项目根目录新建 .env，写入一行：
#    DEEPSEEK_API_KEY=你的密钥

# 4. 抓取数据（公开汇率接口，无需登录）
python fetch_data.py

# 5. 抓取并生成 AI 日报
python generate_report.py
```

**失败即失败：** 抓不到数据、密钥缺失、接口报错时，脚本会直接报错退出，不会用假数据或占位文本兜底。这是刻意设计的 —— 报告里出现的每个数字都必须来自真实抓取。

## 常见问题

### 一、抓不到数据怎么办？

按顺序排查，别急着改代码：

1. **先确认网络通不通。** 浏览器打开 `https://open.er-api.com/v6/latest/USD`，能看到一段 JSON 就说明网络没问题；打不开就先解决网络。
2. **确认目标网站是公开的。** 本工具只抓公开、无需登录的数据。如果对方要登录、要验证码，或 robots.txt 明确禁止抓取，那就不该抓 —— 换个数据源。
3. **看具体报错。** 脚本不吞错误，报错信息里通常已写明原因：
   - `ConnectionError` / `Timeout` —— 网络不通，或对方响应太慢（可调大 `fetch_json(..., timeout=30)`）。
   - `HTTPError: 403 / 429` —— 被对方拒绝了，或请求太频繁。放慢频率，别硬刷。
   - `HTTPError: 404` —— URL 写错了，或对方接口已改版。
   - `不是合法 JSON` —— 抓到的是网页而不是数据接口，检查 URL 是否指向接口地址。
4. **确认脚本真的没抓到，而不是你期望它抓到。** 抓不到就是抓不到，**不要让它返回假数据**。宁可报错，也不能编。

### 二、DeepSeek 调用失败怎么排查？

1. **密钥配了没？** 报 `环境变量 DEEPSEEK_API_KEY 未设置` 就是没配。建 `.env`（照 `.env.example` 改），写入 `DEEPSEEK_API_KEY=你的密钥`，注意不要有多余空格和引号。
2. **余额够不够？** `401` 通常是密钥错了或失效；报余额不足则要去 DeepSeek 平台充值。密钥和余额是两回事，别混。
3. **网络通不通？** `ConnectionError` / `Timeout` —— 检查 `https://api.deepseek.com` 是否可达。
4. **真失败了就让它失败。** 脚本会以非零退出码结束，**不会退回一段编造的报告**。这是故意的。

### 三、跑测试

```bash
pytest test_smoke.py -v
```

冒烟测试验证三件事：能抓到公开数据、能正确提取目标字段、缺密钥时确实非零退出。需要联网。
